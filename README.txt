Software Engineering Lab Repository

This repository contains the coursework and deliverables for the Software Engineering subject.

Project Overview
The current work is based on Problem Statement #14: Corporate Mental Wellness & Counseling Platform.
This project focuses on designing a digital platform that supports employee mental wellness, confidential counseling, and structured support services within an organization.

Repository Structure
- Lab 1/
  - Requirements and use case documentation for the platform
  - UML use case diagram and related artifacts
- Lab 2/
  - To be updated with the next lab deliverables
- Lab 3/
  - To be updated with the next lab deliverables

Lab 1 Deliverables
1. 01_Requirements_Table.docx
   - Includes exactly 5 functional requirements and 2 non-functional requirements
   - Covers actors, use cases, relationships, and traceability
2. 02_Use_Case_Flow.docx
   - Contains the core flow for UC-02: Book Confidential Counseling Session
3. 03_UML_Use_Case_Diagram.pdf
   - UML use-case diagram showing both actors, all 7 use cases, include/extend relationships, and legend
4. 04_UML_Use_Case_Diagram.drawio
   - Editable diagrams.net source of the UML diagram

Purpose
This repository is intended to document and organize the lab work, requirements engineering activities, and UML modeling tasks completed during the course.
