Software Engineering Lab Repository

This repository contains the coursework and deliverables completed for the Software Engineering subject.

Project Overview
The work in this repository is based on Problem Statement #14: Corporate Mental Wellness & Counseling Platform.
The project focuses on designing a digital platform that supports employee mental wellness, confidential counseling, and structured support services within an organization.

Repository Structure
- Lab 1/
  - Requirements specification and use-case modeling artifacts
  - UML use-case diagram and supporting documentation
- Lab 2/
  - Jira-based project planning and submission materials
- Lab 3/
  - Component modeling and design justification documents

Lab 1 Deliverables
1. 01_Requirements_Table.docx
   - Includes 5 functional requirements and 2 non-functional requirements
   - Covers actors, use cases, relationships, and traceability
2. 02_Use_Case_Flow.docx
   - Includes the core flow for UC-02: Book Confidential Counseling Session
3. 02_Use_Case_Flow.pdf
   - PDF version of the use-case flow

5. 04_UML_Use_Case_Diagram.drawio
   - Editable diagrams.net source of the UML diagram

Purpose
This repository serves as a structured collection of software engineering lab work, including requirement analysis, use-case modeling, project tracking, and component-based design.
